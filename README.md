# The I Have No Clothes Store™

A playful, mobile-first digital wardrobe and AI stylist for one very special person.

## Current version

This starter is a frontend prototype built with:

- HTML
- CSS
- JavaScript
- LocalStorage

It already includes:

- Home screen and Chris AI personality
- Wardrobe uploads
- Clothing categories
- Manual outfit builder
- Mood selector
- Outfit generator prototype
- Saved outfits
- Inspiration gallery
- Responsive mobile design

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## GitHub

Create a new GitHub repository, then:

```bash
git init
git add .
git commit -m "Initial version of The I Have No Clothes Store"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

## Important next steps

The current generator is intentionally local and rule-based. The next development phase should add:

1. AI vision for clothing recognition.
2. A secure backend for AI API calls.
3. Cloud storage for wardrobe images.
4. User accounts / private access.
5. Better outfit compatibility logic.
6. Image generation / virtual try-on.
7. Pinterest-compatible inspiration import.
8. Weather-aware recommendations.
9. PWA installation on phone.
10. Optional notifications and outfit history.

Never put private API keys in frontend JavaScript or commit them to GitHub.
